# 功能缺口与竞品对比路线图

> 2026-10-09 | 基于 2026-10-08 代码基线（v0.1.3）与主流竞品功能调研

## 1. 调研方法

- 代码侧：对 `src/`、`server/`、`mobile/` 全量 grep 验证（笔刷/抠图/滤镜/撤销/快捷键/i18n/视频等关键词均确认不存在），非凭 README 推断。
- 竞品侧：Midjourney V8.2（Edit Model）、即梦 AI（智能画布/Seedance）、Canva Magic Studio、LiblibAI / ComfyUI、ChatGPT（gpt-image）。

## 2. 结论速览

25 项缺失功能收敛为 6 个开发主题，按「复用现有管线程度 × 用户价值」排序：

| 主题 | 内容 | 复用现有能力 | 优先级 |
| --- | --- | --- | --- |
| ① | 笔刷蒙版重绘 + 涂抹消除 | 局部修改管线（矩形→mask） | P0 |
| ② | 一键抠图/换背景 + 真超分 + 老照片修复/上色 | 视觉定位 + 图片模型执行（照搬去水印模式） | P0 |
| ③ | 多图参考 + 角色一致性 | 参考图链路升级为 N 张 + 主体缓存 | P1 |
| ④ | Web 基础编辑（裁剪/旋转/翻转）+ 快捷键 + 全局撤销重做 | 移动端已有变换逻辑直接移植 | P1 |
| ⑤ | 生成参数（seed 等）+ PNG 元数据 + 自由比例 | `png.mjs` 已有 PNG 解析基础 | P1 |
| ⑥ | 风格参考 + 模板市场 + 图生视频 | 需新增任务类型 | P2 |

## 4. 逐项缺失清单

### vs Midjourney
1. 笔刷/精细选区重绘（现仅矩形框选）
2. Pan 连续平移扩图（现只能单次选定目标尺寸）
3. 4 张参考图生图（现图生图仅单图）
4. 风格参考 sref / moodboard（项目风格仅为文字提示词）
5. 参数体系（无 seed / stylize 类风格化参数）
6. 提示词/seed 写入图片元数据（导出后无法溯源复现）

### vs 即梦AI
7. 局部消除（涂抹去除杂物/路人/电线）
8. 智能画布/分层生成（多素材拼贴 + 分层 AI 生成）
9. 画质真超分 / 老照片修复 / 黑白上色
10. 图生视频（整个视频赛道缺失）
11. 模板/风格市场（内置画廊仅提示词文案，无可套用成品模板）

### vs Canva
12. 一键抠图/背景移除与替换（电商刚需）
13. Magic Eraser 笔刷消除 + Restore 恢复笔刷（误擦可回退的成对笔刷）
14. 图层概念（把 AI 图拆成可分层编辑对象）
15. Web 端调色/滤镜/裁剪旋转（Web 反而落后于自家移动端）
16. Brand Kit（Logo/字体/色板复用 → 「项目风格」升级方向）

### vs LiblibAI / ComfyUI
17. 完整生成参数（seed/步数/CFG/采样器）
18. ControlNet 类结构控制（姿势/边缘/深度约束）
19. X/Y 参数矩阵对比图（一次出九宫格对比参数效果）
20. 快捷键体系（全程鼠标点击，重度用户效率低）
21. LoRA/模型市场（多提供商接入算部分对标，无自定义微调）

### vs ChatGPT gpt-image
22. 多图融合（"把这张衣服 P 到那张模特"需 ≥2 张输入）
23. 角色一致性链（同一角色连续出多张，分镜/绘本核心）
24. 任意长宽比（受模型尺寸白名单限制，无 3:1 长图）

### vs 美图/醒图
25. 滤镜/调色/美颜、拼图/海报排版（大众高频动作 + 交付最后一公里）

## 5. 主题①详细范围（本路线图首个落地项）

**笔刷蒙版重绘 + 涂抹消除**：将局部修改的矩形选区升级为笔刷蒙版。

- 前端：画布上叠加蒙版绘制层，画笔涂抹（可调粗细）、橡皮擦除、清除全部；蒙版以灰度 PNG 随请求上传。
- 后端：`local-edit` 流水线接受 mask；按蒙版包围盒裁剪 → 视觉规划 → 图片模型生成 → 按蒙版羽化回填，框外保留原图像素。
- 消除模式：指令为空时默认"移除蒙版内物体并自然补全背景"（对标 Magic Eraser / 局部消除）。
- 保持兼容：原矩形框选流程不变，笔刷为新增入口。
- 详细设计：`docs/superpowers/specs/2026-10-09-brush-mask-edit.md`
